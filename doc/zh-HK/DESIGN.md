## 設計目標

- 利用 SMART 狀態及屬性,SMART 錯誤/自我測試日誌,掛載狀態,核心 I/O 錯誤和趨勢快速評估 HDD;提供啟發式評分及可據以行動的等級,而非故障概率.
- 分別提供磁碟內部的 SMART 短測試/長測試,抽樣原始讀取,可續掃的表面延遲掃描,可選擇針對特定位置以唯讀 `badblocks` 複查,全碟唯讀 `badblocks` 檢查,以及維修後的介面讀取壓力測試.
- 支援互動式選取,批次執行,結果持久儲存,重用及歷史報告;長時間工作可選擇交由暫時性 systemd unit 執行.
- 不包括數據復原,寫入模式 `badblocks`,安全抹除及檔案系統修改.Bash 檢查器維持單次執行;可選的本機 Web 配套服務提供常駐控制器及定時快速檢查.可選擇納入 SSD/NVMe,但 HDD 評分並非設計用來全面診斷這類裝置.JSON 快照供 Web UI 使用;更深入的 SAS 評分及 NVMe 專用評分仍未實作.

## 架構

`src/checker/hdd-health-check.sh` 中的檢查器實作透過儲存庫根目錄的相容入口呼叫.它使用 `lsblk` 列舉磁碟,透過選單或命令列選擇目標,以 `smartctl` 探測 SMART 存取,執行指定模組及產生綜合報告.ATA SMART 屬性與 SAS/SCSI 缺陷/錯誤計數器採用不同評分路徑.快速檢查包含掛載和核心紀錄證據;速度,表面和介面檢查直接讀取原始裝置.結果與每個裝置的識別資料持久保存,供後續檢查重複使用.互動式決策可透過受限計劃傳遞給批次程序;私人鎖定機制防止共用狀態目錄的執行個體同時運作.可用時以暫時性 `systemd-run` 單元處理分離式工作;`--status` 和 `--stop` 查詢已記錄的執行個體.

完整批次以同一標記記錄快速,短測,長測 SMART 檢查及已完成的唯讀表面掃描;網頁批次選項展示所選磁碟支援項目的聯集,僅適用於 HDD 的模組會跳過不適用的 SSD;HDD 另須速度取樣.SSD 慢讀只記錄為效能變化,不扣健康分,但實際讀取錯誤仍會扣分.批次最後複查快速 SMART/ATA/CRC,記錄掃描後變化.只有同批次完整且有效的結果才有數字綜合分數.重複使用,中斷,過期,無批次標記的舊狀態和後續介面驗證,會讓舊紀錄維持歷史/待複查狀態,整體等級為部分/未知.僅產生報告不更新快檢比較基準.介面驗證另行記錄已解決或未解決,不重新歸因舊錯誤,也不讓舊批次變成目前批次.沒有先前快檢計數的 ATA 總數仍屬未解決風險(扣 5 分);後續檢查及完整評估繼續保留,即使舊紀錄缺少風險欄位.總數增加扣 20 分;計數穩定既不證明問題解決,也不構成新錯誤.介面驗證不能單獨把 ATA 錯誤歸因於介面維修.零星慢讀提示重測效能,並非壞磁區診斷;反覆發生的表面讀取錯誤仍扣 40 分.這些是啟發式權重,不是故障機率.

快檢中的通電時長僅作為使用資訊顯示,本身不扣健康分.ATA Pre-fail 屬性接近閾值時,必須有非零原始錯誤計數佐證才會警告;缺少原始證據的歷史閾值警告列為待複查,不扣分.新警告記錄包含 SMART 屬性及實測值.關注卡片直接顯示儲存的檢查原因.Web 檢查和停止確認採用可存取的頁面內對話框.磁碟詳情使用完整的次級路由,以型號為頁面標題,設備路徑置於標題下方.

對於固態盤,速度採樣下降及兩次運行之間的平均速度變化只屬於性能觀察,不會降低健康分;實際讀取失敗仍會扣分.此前儲存的速度結果也按同樣方式解釋,無需改動狀態檔案.Web 磁碟列表按可用 CSS 視口寬度儘量排列卡片,足夠寬時最多六列;瀏覽器縮放改變寬度後會重新排布.儀表盤的磁碟卡片可滾動到列表.前端位於 `src/web/`,構建到 `dist/web/`;`src/web/src/theme.css` 為淺色和深色模式下的八套主題色定義語義變量.設置頁將主題色和明暗模式分別儲存到瀏覽器存儲,並在 Vue 掛載前恢復.登入頁使用共用的 72 px 頁眉,最大寬度 480 px 的卡片,48 px 的輸入框及操作按鈕,以及左側版本連結和右側語言選擇器的卡片頁腳;窄屏時頁腳會換行.每個供用户輸入的密碼字段均有獨立的帶標籤 44 px 顯示/隱藏控制項,初始均為遮蔽狀態.登入前仍顯示 IP 登入操作;是否允許該地址由服務端決定.Vite 嵌入構建版本並生成供 `/api/build` 使用的 `version.json`;Changelog 從打包源碼中渲染相應的 `doc/<lang>/LOG.md`.測試構建在正式版本歷史上方增加一個本機化條目,標題使用準確的構建標識.登入前可通過版本連結閲讀打包的 Changelog;磁碟和設置 API 仍需認證.外層列表和 SMART 詳情的序列號保持遮蔽,直到用户點擊帶標籤的顯示按鈕;關閉詳情時再次遮蔽.

每條已認證路由共用一個頁眉,其中項目名和構建版本是連結,隨後依次是首頁,Changelog,設置和退出登入.功能入口仍在儀表盤上;返回控制項將功能頁和 Changelog 帶回儀表盤,將 Security Settings 帶回普通設置.普通設置通過響應式分區導航組織常規,外觀,磁碟行為和安全內容;受保護的 Security Settings 則組織密碼和 IP 控制項.安全分區導航只滾動到入口卡片,另有獨立操作打開受保護路由.每個頁面在共用項目框架中選用不同的 favicon.可選 Beta 頁面過渡採用來源控制項的幾何形狀來打開和返回,追蹤瀏覽器歷史,並可在外觀設置中關閉.用户選擇儲存在 URL,瀏覽器存儲及 Cookie 中;iOS 和 Android 默認關閉.響應式尺寸變化動畫和減少動態效果的處理獨立於此開關.

參考設計包含靜態示例數據及僅供演示的安全對話框.本項目使用實時磁碟及任務狀態,只讀靜態預覽限制,認證後的序列號顯示以及服務端存取控制.這些內容及權限差異是有意保留的.參考設計未涵蓋存儲容量彙總,完整評估,SMART 屬性,任務日誌,定時設置持久化或磁碟詳情頁,因此這些內容採用其卡片和控制項結構,而不換成示例數據.磁碟詳情標籤底線直接對實測寬度執行動畫,而不是縮放參考設計的一像素線條;這樣保持相同時序,並避免縮放時寬度被放大.SMART 懸停/聚焦說明僅為一般指導:屬性的刻度及含義可能因廠商而異.僅在 NVMe Data Units 或具有已知邏輯扇區大小的 ATA Device Statistics 提供數據時,才顯示 SSD/NVMe 主機讀寫總量;單位不明的廠商專屬 ATA 屬性仍顯示為不可用.

## 設計限制

- 有效診斷需要 root 權限及實體 SMART 透傳能力.USB/RAID 橋接偵測屬啟發式;透傳失敗會如實報告,不會推斷磁碟健康.SAS 評分與 ATA 不同,且測試程度較低.溫度及閾值取決於廠商數據.
- 所有裝置表面及介面讀取均指向 `/dev/null`;呼叫 `badblocks` 時不使用破壞性的 `-w`.**啟用 SMART 及自我測試可能改變磁碟韌體狀態**;主機上的路徑亦可寫入.不可將執行過程描述為完全沒有副作用.
- 明確選取裝置或指定 `--include-ssd`,都不代表裝置能安全承受負載.全碟表面掃描可能需時數小時;其他程序的作業系統寫入仍會繼續.`--stop` 不會終止磁碟內部正在執行的自我測試.
- 狀態及計劃數據只按允許的欄位解析,不會當作 shell 程式碼執行.既有但不符合規範的狀態可能被拒絕.主機狀態目錄不可為符號連結;腳本會檢查目錄及輸出日誌的符號連結,但呼叫者仍須保護自己選用的路徑.

## 數據設計

`HDD_STATE_DIR` 預設為 `/var/lib/hdd-health`(以 700 權限建立).其中存放 `settings.conf`(有效天數,重用政策,並行數,掃描區塊大小,抽樣參數,是否納入 SSD 及自動複查政策),每隻磁碟的 `.env` 結果檔,SMART 計數器 `history.csv`,維修日誌,表面狀態圖/檢查點,報告歷史紀錄及可選的壞區塊清單.`.lock`,執行中實例資料和暫存的背景工作計劃負責協調執行.預設設定包括七天結果有效期,64 MiB 表面掃描區塊及 24 × 128 MiB 速度抽樣.選單可儲存設定;`--rescan` 會覆蓋重用設定.清除結果時可保留或刪除計數器/維修歷史紀錄;使用者亦可另外選擇刪除舊日誌.

`HDD_LOG_DIR` 預設為 `/var/log/disk-health`;`-l/--log` 可指定單一日誌.日誌為純文字,可能包含裝置識別資料,主機/核心細節及健康數據,應妥善保護.暫存工作目錄會建立在 `/run` 下,或使用後備暫存目錄.不可假設日誌是唯一的持久輸出,亦不可假設沒有配套備份便能將較新版本的狀態目錄回退.

## 外部介面

| 介面 | 職責及影響 |
| --- | --- |
| `lsblk`,`blockdev`,`/proc/mounts`,核心日誌 | 列出裝置,取得幾何資訊,掛載狀態及 I/O 錯誤;可見資料取決於主機權限. |
| `smartctl` | 讀取 SMART 診斷數據;可啟用 SMART 或啟動內部測試.透傳選項的自動偵測屬啟發式. |
| `dd`,`badblocks` | 直接讀取原始裝置,以作抽樣,介面負載,延遲掃描或唯讀壞區塊測試.讀取可能令狀況欠佳的硬件承受壓力. |
| `apt-get` | 提議安裝缺少的套件;`-y` 可自動接受.這會更改主機套件,亦可能需要網絡連線. |
| `systemd-run` | 用於脫離終端工作的可選暫時性 unit;`--stop` 要求關閉腳本已記錄的程序,而非硬件自我測試. |

健康檢查本身不使用網路 API.可選的本機 Web 服務在手動模式下使用回環 API;安裝程式啟用經驗證的區域網路存取.`--json` 使用與終端報告相同的綜合評分函式提供結構化唯讀快照.Web 登入發放短時效,僅供 HTTP 使用的會話 Cookie.安全驗證會輪換該 Cookie,然後授予五分鐘權限;變更狀態的請求包含同源請求標頭作為 CSRF 防護.私人地址允許名單啟用後可在一般操作中略過密碼登入.Security Settings 將允許名單,啟用開關及密碼修改置於伺服端強制執行的五分鐘權限之後,該權限由管理員密碼驗證授予.僅透過 IP 進入的會話不能讀取或修改這些設定.在權限有效期間,修改密碼只須輸入並確認新密碼,不用再次輸入目前密碼;修改後所有會話失效.預設快照和 SMART 回應會遮蔽序號;只有使用者明確操作後,獨立且經驗證的顯示端點才傳回完整序號.服務只在開啟磁碟時按需讀取 SMART 詳情;原始 SMART 結論不取代檢查器的綜合分數.`--no-install` 防止無人值守呼叫時安裝套件.Web 架構,排程及安全邊界見 [WEB](WEB.md).Web 原始碼位於 `src/web/`,產生的建置結果位於 `dist/web/`;安裝程式將其複製到既有主機佈局.腳本可使用結束代碼 `0` 健康,`1` 需注意,`2` 危險,`3` 執行階段錯誤;請參閱[指引](README.md#指引).

磁碟容量使用共用的十進制/二進制單位切換控制項和獨立詳情連結,卡片其餘區域不可交互.磁碟快照包含來自 `lsblk` 的物理容量和已掛載檔案系統用量,按 UUID 去重掛載檔案系統,以及映射至已枚舉磁碟的 ZFS 存儲池分配量.存在 RAID 或未掛載卷時,這些數值的統計範圍不同.SSD 詳情從 NVMe Data Units 或明確提供邏輯扇區大小的 ATA Device Statistics 計算主機讀寫量,廠商專屬計數器仍為未知.Web 評估端點按 SATA 傳輸類型,旋轉屬性,SSD 旋轉屬性,NVMe 標識或全部磁碟過濾服務端當前枚舉結果.它為所選磁碟提供受支持模塊的並集,用選中的設備名稱啓動一個後台 `<module> --rescan` 批次,需要時加上 `--include-ssd`.此操作絕不接受瀏覽器提交的設備名稱.鏈路數據來自 smartctl 的 SATA 版本和當前速度,以及 Linux sysfs 中最近的可用 SATA 或 NVMe PCIe 鏈路;缺失字段保持未知.儀表盤分別根據旋轉屬性和傳輸類型識別介質,並通過有界後台 SMART 探測讀取温度,默認不會喚醒待機 SATA 磁碟.私有 Web 偏好可選擇每次存取頁面時依次喚醒休眠的機械盤;待機狀態會明確標識,不顯示成温度缺失.SMART 詳情在設備提供時顯示外形規格;僅憑傳輸類型不能確認 M.2 外形.SSD/NVMe 可以執行 SMART 快檢,短測,長測,全盤只讀掃描和完整評估.HDD 專用模塊(包括速度採樣,badblocks 和接口複查)會跳過選中的 SSD;如果選擇中有適用的 HDD,這些模塊仍可使用.SSD 完整批次不做速度採樣;批次完成後產生當前啟發式評分,所有必需檢查均無異常時為 100 分.該評分並非經過校準的故障概率.休眠 HDD 可從其 SMART 詳情頁單獨喚醒.

需要關注卡片現會篩出有警告或異常紀錄的磁碟.檢測詳情列出原因及扣分;舊紀錄扣分但未儲存原因時會明確提示重新檢查.背景任務由已提交,執行中到完成,停止或失敗都會留下狀態紀錄及最近日誌.提交後 15 秒仍沒有執行或結束紀錄時顯示狀態未確認.返回碼 `1` 或 `2` 表示檢測完成但發現問題,並非啟動失敗.

## 目前固態硬碟評估與操作

SSD/NVMe 的完整評估執行 SMART 快檢,短測和長測及全盤只讀掃描.它不進行速度採樣;單純慢讀不扣健康分.完整且無異常的批次得 100 分,SMART 異常或實際讀取錯誤可能降低啟發式評分.所選磁碟包含 SSD 時,Web UI 只提供快檢,短測,長測,只讀掃描和完整評估.點擊容量及主機寫入量可在十進制與二進制單位之間切換.休眠 HDD 的 SMART 詳情頁提供只喚醒該磁碟的按鈕.
