# hdd-health-check

تقيّم أداة Bash هذه، التي تُشغَّل بصلاحيات الجذر، حالة الأقراص الصلبة HDD على Debian/Ubuntu باستخدام بيانات SMART وفحوص القرص للقراءة فقط. الشيفرة المصدرية لـ v2.2.0 متاحة على GitHub في مستودع عام. أفاد المستخدم باختبارها على جهاز فعلي دون تحديد الأجهزة أو البيئة أو نطاق الاختبارات؛ لا يوجد وسم v2.2.0 أو GitHub Release.

## Introduction

تتيح القائمة التفاعلية أو واجهة سطر الأوامر للتشغيل الدفعي اختيار الأقراص، وإجراء تقييم سريع لبيانات SMART وحالة التركيب وسجل النواة، ثم عرض درجة تقديرية من 0 إلى 100 ومستوى للمخاطر. وتوفر وحدات أخرى اختبارات SMART ذاتية قصيرة وطويلة، وقياس سرعة القراءة بأخذ عينات، ومسحًا قابلًا للاستئناف لزمن تأخر القراءة عبر القرص كله مع إعادة فحص موجّهة اختيارية باستخدام `badblocks`، وفحصًا كاملًا للقرص باستخدام `badblocks` للقراءة فقط، واختبار قراءة للواجهة بعد الإصلاح. يشغّل التقييم الكامل الفحوص السريعة والقصيرة والطويلة وفحص السرعة والسطح؛ ولا يشمل وحدة `badblocks` المنفصلة للقرص كله أو وحدة الواجهة. يمكن إعادة استخدام النتائج ومقارنتها بسجل عدادات SMART وجمعها في تقرير. راجع [المشكلات المعروفة](LOG.md#bugs) و[الأهداف](DESIGN.md#design-goals).

**القراءة فقط تعني بيانات القرص المستهدف، لا المضيف.** يكتب البرنامج السجلات والإعدادات ومعلومات التقدم والسجل التاريخي على المضيف؛ وقد يفعّل SMART، ويبدأ اختبارات ذاتية داخل القرص، ويقرأ أجهزة كاملة تحت حمل مستمر، ويثبّت حزمًا بعد التأكيد، ويبدأ وحدات systemd مؤقتة. لا تستخدمه بديلًا عن النسخ الاحتياطية. ولا يتضمن مسحًا تخريبيًا للسطح بوضع الكتابة أو محوًا أو كتابةً على نظام الملفات.

## Requirements

- الحد الأدنى: صلاحيات الجذر، وBash 4.3+، وأدوات أجهزة الكتل على Linux (`lsblk` و`blockdev`)، و`smartctl` (`smartmontools`)، و`dd` (`coreutils`)، و`flock`؛ والمنصة المستهدفة هي Debian/Ubuntu. يظهر تحذير على التوزيعات الأخرى؛ ويستخدم تثبيت الاعتماديات الآلي `apt-get`.
- الموصى به: `badblocks` (`e2fsprogs`) لفحوص السطح؛ وsystemd مع `systemd-run` للمهام المنفصلة. قد يؤدي غياب حزم إلى عرض تثبيتها تفاعليًا عبر `apt-get update`/install (أو إلى الموافقة التلقائية باستخدام `-y`). تحقّق من الاعتماديات قبل التشغيل دون مراقبة. لا تتضمن الحزمة شيفرة لطرف ثالث مثبتة الإصدارات، ولا ينطبق ملف قفل للاعتماديات.
- يلزم قرص HDD فعلي وإمكانية الوصول إلى SMART لتقييم الحالة الفعلية. يمكن تضمين SSD/NVMe صراحةً، لكن نظام التقييم المصمم للأقراص HDD ليس تقييمًا معايرًا لـ SSD/NVMe.

## Install

### Quick Install

من نسخة مصدر موثوقة، شغّل `sudo bash ./hdd-health-check.sh --help` للاطلاع على الخيارات دون بدء المسح. لا تمرّر نصًا برمجيًا بعيدًا لم تراجعه إلى صدفة بصلاحيات الجذر.

### Normal Install

```bash
git clone https://github.com/CharlesGool/hdd-health-check.git
cd hdd-health-check
bash -n hdd-health-check.sh
sudo bash ./hdd-health-check.sh --help
```

راجع حزم نظام التشغيل المطلوبة وثبّتها بنفسك قبل المسح لتجنّب مطالبة النص البرمجي بتثبيتها. لترقية نسخة موجودة، انسخ احتياطيًا أولًا أي سجلات مضيف تريد الاحتفاظ بها و`${HDD_STATE_DIR:-/var/lib/hdd-health}`؛ ثم استبدل النص البرمجي بنسخة من مصدر راجعته، واحتفظ بدليل الحالة لاستبقاء السجل وإمكانية الاستئناف، ثم راجع `--help` وشغّل الفحوص المختارة. لا يقبل تحليل الحالة في v2.2 إلا حقول البيانات المعروفة؛ وقد يرفض بيانات حالة سابقة من v2.2 لا تطابق التنسيق. يتطلب الرجوع إلى إصدار سابق استعادة النص البرمجي السابق **ونسخته الاحتياطية المطابقة من الحالة**؛ لا تفترض توافق الحالة الأحدث مع الإصدارات السابقة. لا يوجد وعد بدعم سلوك CLI الخاص بـ v1 أو بترحيل حالته.

## إرشادات الاستخدام

لا تشغّل الأداة إلا على أقراص مخوّل لك فحصها؛ فقد يضيف المسح المستمر بالقراءة حملًا كبيرًا. الأوامر التالية **أمثلة، وليست تعليمات تحقق لهذه البيئة**:

```bash
sudo bash ./hdd-health-check.sh                 # terminal menu
sudo bash ./hdd-health-check.sh -a              # all rotational disks, default quick scan
sudo bash ./hdd-health-check.sh -d sdb -r quick,short
sudo bash ./hdd-health-check.sh -d sdb -r full -y
sudo bash ./hdd-health-check.sh -d sdb -r iface --duration 30 --detach
sudo bash ./hdd-health-check.sh --status
sudo bash ./hdd-health-check.sh --stop
```

يقبل `-d/--disk` أسماء أجهزة مفصولة بفواصل؛ ويختار `-a/--all` الأقراص الميكانيكية، بينما يوسّع `--include-ssd` نطاق الاختيار. يقبل `-r/--run` القيم `quick,short,long,speed,surface,badblocks,iface,full`؛ والقيمة الافتراضية `quick`، ويضيف الوضع الدفعي تقريرًا دائمًا. يحدد `--duration` مدة اختبار الواجهة بالدقائق (الافتراضي 15). يبدأ `--rescan` الفحص من جديد بدل إعادة استخدام النتائج السابقة أو استئنافها؛ افتراضيًا، يُعاد الفحص السريع في الوضع الدفعي، وتُعاد الاستفادة من النتائج الأخرى ما دامت صالحة، وتُستأنف فحوص السطح المتوقفة. يخفي `-q/--quiet` مخرجات الطرفية **لا كتابة السجلات**؛ ويوافق `-y/--yes` تلقائيًا على المطالبات، بما فيها تثبيت الحزم. يتطلب `--detach` الوضع الدفعي وتوفر `systemd-run`؛ وقد يؤدي انقطاع الطرفية أثناء المهام التفاعلية الطويلة المؤهلة إلى نقلها إلى systemd أيضًا. يطلب `--stop` إيقافًا آمنًا ويحفظ تقدم فحص السطح، لكنه **لا** يلغي اختبارات SMART الذاتية الجارية داخل القرص. يغيّر `-l/--log FILE` مسار السجل؛ ويتجاوز `HDD_LOG_DIR` و`HDD_STATE_DIR` الدليلين الافتراضيين. يعطّل `NO_COLOR` الألوان؛ ويعطّل `HDD_NO_BG` النقل التلقائي إلى الخلفية أثناء التشغيل التفاعلي. تُحفظ إعدادات القائمة في دليل الحالة.

يحوّل المحلّل أيضًا `-t short|long` إلى الاختبار الذاتي المقابل، و`-s` إلى فحص السرعة، و`-b` إلى badblocks؛ أما **`-w/--wait` فيُتجاهل** ولا ينتظر اكتمال الاختبار. لا توفر هذه الاختصارات سلوك v1. ارجع إلى `--help` لمعرفة خيارات النص البرمجي المثبّت.

رموز الخروج: `0` جميعها سليمة؛ `1` تنبيه/تحذير؛ `2` خطر؛ `3` خطأ أثناء التشغيل. تُحفظ السجلات افتراضيًا في `/var/log/disk-health/hdd-health-<timestamp>.log`، والحالة في `/var/lib/hdd-health`. ترد تفاصيل الكتابة على المضيف وحدود التشغيل في [DESIGN](DESIGN.md#data-design).

## إزالة التثبيت

- احذف نسخة المصدر أو النص البرمجي المثبّت لإزالة الأداة مع الإبقاء على السجلات والبيانات التاريخية. لا تُثبَّت خدمة systemd دائمة؛ تحقّق من عدم وجود مهام مؤقتة نشطة قبل إزالة النص البرمجي.
- للإزالة الكاملة، أوقف أولًا أي مهمة وانسخ السجلات التي ترغب في الاحتفاظ بها احتياطيًا، ثم احذف يدويًا `HDD_STATE_DIR` المضبوط (الافتراضي `/var/lib/hdd-health`) و`HDD_LOG_DIR` المضبوط (الافتراضي `/var/log/disk-health`) بعد التحقق من مساراتهما ومحتوياتهما. يحذف ذلك التقارير والتقدم والبيانات التاريخية وملاحظات الإصلاح والسجلات؛ لا تحذف أبدًا دليلًا مشتركًا أو دليلًا أعيد تحديده دون تحقق. لا تُزال الحزم المثبتة عبر `apt-get` تلقائيًا.
