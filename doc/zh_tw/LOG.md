## 已知問題

- [ ] 本次整合尚未驗證實體 HDD、root／套件安裝與 systemd 行為；先前 v1.0.0 發布檢查也缺少實體 HDD 與 SMART 資料（僅檢查語法及說明）。據報在最初的標準化之前曾使用過此腳本，但不能以此取代受控的硬體測試。
- [ ] 啟發式健康評分的權重並非經過校準的故障機率；SAS/SCSI 評分的測試少於 ATA，USB/RAID 的 SMART 透傳也可能失敗。依廠商而異的溫度回報尚不完整。
- [ ] 沒有結構化 JSON/CSV 輸出。不符合格式的既有 v2.2 狀態會遭拒；自訂 `TMPDIR` 時的背景狀態偵測與安全停止、異常磁碟表面進度現已通過隔離模擬測試；實際 systemd 與 HDD 行為仍未驗證。
- [x] v1.0.0 標準化時，修正了指向不存在之 `hdd-health-check-repo/main` 路徑的複製儲存庫說明，以及簡體中文 README 中混用繁體字的問題。

## 變更紀錄

### 尚未發布 — v2.2.0 整合（尚無發布日期）

#### 新增

- 持久保存各磁碟的結果、SMART 計數器歷史紀錄、修復紀錄及報告；互動式選單、抽樣讀取分析、可續掃且可針對特定區域重新檢查壞區塊的磁碟表面延遲掃描、全碟唯讀 `badblocks`、介面讀取壓力測試，以及可選的暫時性 systemd 背景執行。

#### 變更

- 預設的批次快速檢查、可在有效期間重複使用的結果及 `--rescan`；`-r/--run` 選取模組，`--status`／`--stop` 管理執行中的個體。`-t short|long`、`-s` 與 `-b` 對應至模組；`-w/--wait` 會被忽略，而非等待完成。新行為不相容於 v1 命令列介面。
- 主機狀態與日誌分別寫入；所提供的 v2.2.0 整合限制了狀態／計畫資料的解析，以及路徑／裝置處理。本次整合尚未執行實體 HDD、root 或 systemd 整合測試。

### v1.0.0 — 2026-08-08

#### 新增

- 最初的 12 維度 HDD 健康檢查：裝置／介面資料、SMART 能力與整體判斷、ATA 屬性或 SAS 缺陷／錯誤計數器、錯誤與自我測試紀錄、啟動短／長自我測試、使用壽命／負載、核心 I/O 錯誤、掛載與唯讀偵測、可選的唯讀 `hdparm` 效能測試及 `badblocks` 掃描。
- 啟發式的 0–100 分數與四種等級，搭配程序結束代碼 0/1/2/3、SMART 透傳自動偵測、互動式與批次磁碟選取，以及提供安裝缺少的 `smartmontools` 的 `apt` 選項。
- 完整的 v1.0.0 設計與用法文件保留在 `v1.0.0` Git 標籤中（例如 `git show v1.0.0:DESIGN.md` 和 `git show v1.0.0:README.zh.md`）；舊版指令不適用於目前版本。
