## 设计目标

- 使用 SMART 状态与属性,SMART 错误/自检日志,挂载状态,内核 I/O 错误和趋势快速排查 HDD;提供启发式评分和可据此采取行动的等级,而非故障概率.
- 提供独立的磁盘内部 SMART 短程/长程自检,抽样原始读取,可续扫的盘面延迟扫描,可选的针对性只读 `badblocks` 复查,全盘只读 `badblocks`,以及修复后的接口读取压力检查.
- 支持交互式选择,批处理执行,持久化结果,复用及历史报告;可选通过临时 systemd 单元移交长时间运行的任务.
- 不涵盖数据恢复,写入模式 `badblocks`,安全擦除或文件系统修改.Bash 检查器仍是单次运行工具;可选的本地 Web 配套服务负责常驻控制与定时快速巡检.可选择纳入 SSD/NVMe,但 HDD 评分并非为全面诊断这些设备而设计.JSON 快照供 Web UI 使用;更深入的 SAS 评分和 NVMe 专用评分并非已实现目标.

## 架构

`src/checker/hdd-health-check.sh` 中的检查器实现通过仓库根目录的兼容入口调用.它以 `lsblk` 枚举磁盘,通过菜单或 CLI 选择目标,用 `smartctl` 探测 SMART 访问,执行指定模块并生成综合报告.ATA SMART 属性与 SAS/SCSI 缺陷/错误计数器使用不同的评分路径.快速检查包含挂载和内核日志证据;速度,盘面和接口检查使用原始设备读取.结果和每个设备的标识持久保存,供后续检查复用.交互式决定可通过受约束的计划传递给批处理进程;私有锁防止共用状态目录的实例并发运行.可用时由临时 `systemd-run` 单元处理后台任务;`--status` 和 `--stop` 查询已记录的实例.

完整批次以同一批次标记记录快速,短程,长程 SMART 检查及已完成的只读盘面扫描;网页批量选项展示所选磁盘支持的项目并集,仅适用于 HDD 的模块会跳过不适用的 SSD;HDD 还要求速度采样.SSD 慢读只记为性能变化,不扣健康分,但实际读取错误仍会扣分.批次末尾复查快速 SMART/ATA/CRC,记录扫描后的变化.只有同批次完整且有效的结果才有数字综合分数.复用,中断,过期,无批次标记的旧状态及之后的接口验证会让旧记录保持历史/待复查状态,总体等级为部分/未知.仅生成报告不会更新快检比较基线.接口验证另行记录已解决或未解决,不重新归因旧错误,也不让旧批次变成当前批次.没有先前快检计数的 ATA 总数仍属未解决风险(扣 5 分);后续检查和完整评估继续保留,即使旧记录缺少风险字段.总数增加扣 20 分;计数稳定既不证明问题解决,也不构成新错误.接口验证不能单独把 ATA 错误归因于接口维修.零星慢读提示复测性能,并非坏扇区诊断;反复发生的盘面读取错误仍扣 40 分.这些是启发式权重,不是故障概率.

快检中的通电时长仅作为使用信息显示,本身不扣健康分.ATA Pre-fail 属性接近阈值时,需要有非零原始错误计数佐证才会警告;缺少原始证据的历史阈值警告列为待复查,不扣分.新警告记录包含 SMART 属性及实测值.关注卡片直接显示保存的检查原因.Web 检查和停止确认采用可访问的页面内对话框.磁盘详情使用完整的次级路由,以型号为页面标题,设备路径置于标题下方.

对于固态盘,速度采样下降及两次运行之间的平均速度变化只属于性能观察,不会降低健康分;实际读取失败仍会扣分.此前保存的速度结果也按同样方式解释,无需改动状态文件.Web 磁盘列表按可用 CSS 视口宽度尽量排列卡片,足够宽时最多六列;浏览器缩放改变宽度后会重新排布.仪表盘的磁盘卡片可滚动到列表.前端位于 `src/web/`,构建到 `dist/web/`;`src/web/src/styles/tokens.css` 为浅色和深色模式下的八套主题色定义语义变量.设置页将主题色和明暗模式分别保存到浏览器存储,并在 Vue 挂载前恢复.登录页使用共用的 72 px 页眉,最大宽度 480 px 的卡片,48 px 的输入框及操作按钮,以及左侧版本链接和右侧语言选择器的卡片页脚;窄屏时页脚会换行.每个供用户输入的密码字段均有独立的带标签 44 px 显示/隐藏控件,初始均为遮蔽状态.登录前仍显示 IP 登录操作;是否允许该地址由服务端决定.Vite 嵌入构建版本并生成供 `/api/build` 使用的 `version.json`;Changelog 从打包源码中渲染相应的 `doc/<lang>/CHANGELOG.md` (简体中文为 `doc/CHANGELOG.md`).测试构建在正式版本历史上方增加一个本地化条目,标题使用准确的构建标识.登录前可通过版本链接阅读打包的 Changelog;磁盘和设置 API 仍需认证.外层列表和 SMART 详情的序列号保持遮蔽,直到用户点击带标签的显示按钮;关闭详情时再次遮蔽.

每条已认证路由共用一个页眉,其中项目名和构建版本是链接,随后依次是首页,Changelog,设置和退出登录.功能入口仍在仪表盘上;返回控件将功能页和 Changelog 带回仪表盘,将 Security Settings 带回普通设置.普通设置通过响应式分区导航组织常规,外观,磁盘行为和安全内容;受保护的 Security Settings 则组织密码和 IP 控件.安全分区导航只滚动到入口卡片,另有独立操作打开受保护路由.每个页面在共用项目框架中选用不同的 favicon.页面导航立即更新. 窗口调整动画独立运行, 并尊重减少动效偏好.

## 设计标记

唯一来源为 `src/web/src/styles/tokens.css`, 从当前 Web UI 起始模板迁移. `src/web/src/styles/main.css` 加载模板的 Tailwind 与基础样式; `src/web/src/style.css` 仅保留磁盘, 任务, 登录与表单的业务布局.

在 `src/web/` 执行 `npm run check`, 依次检查设计标记, TypeScript 和生产构建. `.claude/settings.json` 在编辑后执行同一设计检查. 检查器保持模板原样, 不使用忽略标记.

共享组件位于 `src/web/src/components/app/`: 顶栏, 返回控件, Toast, 文本宽度下划线标签, 分段控件, 主题选择, 信息提示, 设置分区导航与卡片集合. `components/ui/button/` 使用模板的 shadcn-vue 按钮. 顶栏和页头通过原生链接及事件接入既有历史控制器; 外观选择保留原有浏览器存储键. 界面保留八种语言; 简体中文, 英文与西班牙文为核心文档语言, 其他文档保留兼容入口.

相对模板新增: `--header-height`, `--login-control-height`, `--password-control-size`, `--settings-nav-width` 用于登录与设置尺寸; `--warning` 及三种状态背景区分磁盘风险; `--layer-overlay`, `--layer-popover` 用于确认框与选择列表; `--tracking-eyebrow` 用于辅助标题; `--app-disk-min-width` 用于长设备字段; `--app-size-*` 保留既有磁盘表格, 存储汇总及任务面板的几何尺寸. 字体, 字号阶梯, 字重, 圆角, 阴影, 动效和八色调色板直接使用模板数值.

页面导航立即更新, 不执行页面过渡. 窗口调整仍在停止 180 ms 后使用 620 ms 过渡, 并从标记读取时长. 减少动效时停止主题, 标签, Toast 和窗口动画. 卡片采用可换行的弹性布局, 末行卡片均分宽度. 设置分区跟随滚动更新 `aria-current`; 点击安全导航只滚动到入口卡片. SMART 信息提示支持悬浮, 键盘焦点和触摸; 序列号始终由服务端授权后按需获取.

窗口调整直接复用 `src/web/src/lib/resize-reflow.ts` 的模板实现. `data-reflow` 标记互不嵌套; DOM 与尺寸观察器随数据和页面变化更新位置基线. 切换减少动效或离开视图时取消过渡并清理监听, 避免旧位置引发元素重叠.

## 设计约束

- 读取工具不支持 O_DIRECT, 设备不可访问或路径失效时, 速度, 盘面和接口检查标为未完成, 不把环境错误计入介质错误. 盘面进度保留; 已有真实错误仍在状态记录中. `badblocks` 复查失败或被中断时不宣称异常已消失. 两次读取失败是读取异常证据, 不足以单独证明坏道或归因于介质.
- Web 密码比较支持 UTF-8 输入; 每个地址的错误尝试在同一个锁中检查并记录, 十分钟内最多十次. 过期地址会清理; 地址表满时不驱逐仍有效的限流记录. Web 任务状态使用独立临时文件原子写入.
- systemd 单元在 `network.target` 之后启动, 由 `multi-user.target` 拉起; 不依赖后者之后启动, 避免启动排序环. 状态与日志目录均为 0700.

- 有效诊断需要 root 权限和物理 SMART 透传.USB/RAID 桥接检测基于启发式规则;透传失败会报告出来,而不会被推断为健康.SAS 评分独立于 ATA,验证也比 ATA 少.温度和阈值取决于厂商数据.
- 所有设备盘面和接口读取均输出到 `/dev/null`;调用 `badblocks` 时不使用破坏性的 `-w`.**启用 SMART 和运行自检可能修改磁盘固件状态**;主机路径也可写入.不可将此描述为零副作用执行.
- 显式选择及 `--include-ssd` 不意味着设备可安全承受负载.全盘盘面扫描可能耗时数小时;其他进程的操作系统写入仍会继续.`--stop` 不会终止磁盘内部运行的自检.
- 状态及计划数据仅按允许的字段解析,不作为 shell 代码执行.已有但不符合格式的状态可能被拒绝.主机状态目录不得为符号链接;脚本会检查目录和输出日志的符号链接,但调用者仍须保护自行选择的路径.

## 数据设计

`HDD_STATE_DIR` 默认位于 `/var/lib/hdd-health`(创建权限模式为 700).目录内有 `settings.conf`(结果有效天数,复用策略,并行度,扫描分块大小,采样参数,是否纳入 SSD 及自动复查策略),每盘 `.env` 结果文件,SMART 计数器 `history.csv`,修复日志,盘面扫描图/检查点,报告历史及可选的坏块列表.`.lock`,运行中实例数据和临时后台计划用于协调执行.默认设置包括结果有效期七天,64 MiB 盘面扫描分块和 24 × 128 MiB 速度采样.菜单可保存设置;`--rescan` 会覆盖复用策略.清除结果时可保留计数器/修复历史或一并删除;用户也可另行选择删除旧日志.

`HDD_LOG_DIR` 默认位于 `/var/log/disk-health`;`-l/--log` 选择单个日志的路径.日志为纯文本,可能包含设备标识,主机/内核信息和健康数据,应妥善保护.临时工作目录创建在 `/run` 下,或者回退到临时目录.不要假定日志是唯一的持久化输出,也不要假定新版状态目录在没有匹配备份时可回滚.

## 外部接口

| 接口 | 职责及影响 |
| --- | --- |
| `lsblk`,`blockdev`,`/proc/mounts`,内核日志 | 枚举设备,获取几何参数与挂载状态及 I/O 错误;可见信息受主机权限限制. |
| `smartctl` | 读取 SMART 诊断信息;可能启用 SMART 或启动内部自检.透传选项的自动检测基于启发式规则. |
| `dd`,`badblocks` | 对原始设备进行采样,接口负载,延迟扫描或只读坏块测试.读取可能加重受损硬件的负担. |
| `apt-get` | 提示安装缺少的软件包;`-y` 可自动同意.这会更改主机软件包,并可能需要网络访问. |
| `systemd-run` | 用于分离式任务的可选临时单元;`--stop` 请求停止脚本记录的进程,而非硬件自检. |

健康检查本身不使用网络 API.可选的本地 Web 服务在手动模式下使用回环 API;安装器启用带认证的局域网访问.`--json` 使用与终端报告相同的综合评分函数提供结构化只读快照.Web 登录发放短时效,仅供 HTTP 使用的会话 Cookie.安全验证会轮换该 Cookie,然后授予五分钟权限;改变状态的请求包含同源请求头作为 CSRF 防护.私有地址白名单启用后可在普通操作中跳过密码登录.Security Settings 将白名单,启用开关及密码修改置于服务端强制的五分钟权限之后,该权限通过管理员密码验证授予.仅通过 IP 进入的会话不能读取或修改这些设置.在权限有效期内,修改密码只需输入并确认新密码,无需再次输入当前密码;修改后所有会话失效.默认快照和 SMART 响应会遮蔽序列号;只有用户明确操作后,独立的认证显示接口才返回完整序列号.服务只在打开磁盘时按需读取 SMART 详情;其原始 SMART 结论不替代检查器的综合评分.`--no-install` 阻止无人值守调用时安装软件包.Web 架构,时间表及安全边界见 [WEB](WEB.md).Web 源码位于 `src/web/`,生成的构建产物位于 `dist/web/`;安装器将其复制进现有主机布局.脚本可使用退出码 `0` 健康,`1` 需关注,`2` 危险,`3` 运行失败;参见[指南](../README.md#指南).

磁盘容量使用共用的十进制/二进制单位切换控件和独立详情链接,卡片其余区域不可交互.磁盘快照包含来自 `lsblk` 的物理容量和已挂载文件系统用量,按 UUID 去重挂载文件系统,以及映射至已枚举磁盘的 ZFS 存储池分配量.存在 RAID 或未挂载卷时,这些数值的统计范围不同.SSD 详情从 NVMe Data Units 或明确提供逻辑扇区大小的 ATA Device Statistics 计算主机读写量,厂商专属计数器仍为未知.Web 评估端点按 SATA 传输类型,旋转属性,SSD 旋转属性,NVMe 标识或全部磁盘过滤服务端当前枚举结果.它为所选磁盘提供受支持模块的并集,用选中的设备名称启动一个后台 `<module> --rescan` 批次,需要时加上 `--include-ssd`.此操作绝不接受浏览器提交的设备名称.链路数据来自 smartctl 的 SATA 版本和当前速度,以及 Linux sysfs 中最近的可用 SATA 或 NVMe PCIe 链路;缺失字段保持未知.仪表盘分别根据旋转属性和传输类型识别介质,并通过有界后台 SMART 探测读取温度,默认不会唤醒待机 SATA 磁盘.私有 Web 偏好可选择每次访问页面时依次唤醒休眠的机械盘;待机状态会明确标识,不显示成温度缺失.SMART 详情在设备提供时显示外形规格;仅凭传输类型不能确认 M.2 外形.SSD/NVMe 可以执行 SMART 快检,短测,长测,全盘只读扫描和完整评估.HDD 专用模块(包括速度采样,badblocks 和接口复查)会跳过选中的 SSD;如果选择中有适用的 HDD,这些模块仍可使用.SSD 完整批次不做速度采样;批次完成后产生当前启发式评分,所有必需检查均无异常时为 100 分.该评分并非经过校准的故障概率.休眠 HDD 可从其 SMART 详情页单独唤醒.

需要关注卡片现在会筛出有警告或异常记录的磁盘.检测详情列出原因和扣分;旧记录扣分但未保存原因时会明确提示重新检查.后台任务从已提交,运行中到完成,停止或失败都会留下状态记录及最近日志.任务提交后 15 秒仍没有运行或结束记录时显示状态未确认.检测返回码 `1` 或 `2` 表示检查完成但发现问题,并非启动失败.

## 当前固态盘评估与操作

SSD/NVMe 的完整评估执行 SMART 快检,短测和长测及全盘只读扫描.它不进行速度采样;单纯慢读不扣健康分.完整且无异常的批次得 100 分,SMART 异常或实际读取错误可能降低启发式评分.只选择 SSD 时, Web UI 提供快检, 短测, 长测, 只读扫描和完整评估. 混合选择时提供所支持模块的并集, HDD 专用项目跳过 SSD.点击容量及主机写入量可在十进制与二进制单位之间切换.休眠 HDD 的 SMART 详情页提供只唤醒该磁盘的按钮.
