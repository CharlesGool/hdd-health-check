## 缺陷

- [ ] 真实 HDD 完整评估与 NAS 重启恢复未完成受控验证. 合成测试和界面截图不能替代硬件测试.
- [ ] USB/RAID SMART 透传及 SAS/SCSI 厂商数据覆盖有限, 无法保证所有设备提供相同字段.
- [ ] 固件自检日志时间精度可能导致新完成记录难以区分, 此时保守显示未完成或未知.

## 限制

- 健康分是启发式指标, 未校准为故障概率; SSD/NVMe 使用当前检查规则, 不代表厂商寿命保证.
- Bash 终端与持久化检查摘要沿用简体中文字面输出, 厂商原始诊断不翻译; Web 控件有八种语言. 改变状态文本与 CLI 识别逻辑需要单独的兼容迁移.
- 安装器仅支持 Debian 和固定的应用/服务布局. 默认 LAN HTTP 不加密凭据, 仅用于可信局域网或 SSH 隧道.
- 不提供 v1 CLI/状态迁移保证, 不符合当前格式的旧 v2.2 状态会被拒绝.
