## 设计目标

- 使用 SMART 状态与属性,SMART 错误/自检日志,挂载状态,内核 I/O 错误和趋势快速排查 HDD;提供启发式评分和可据此采取行动的等级,而非故障概率.
- 提供独立的磁盘内部 SMART 短程/长程自检,抽样原始读取,可续扫的盘面延迟扫描,可选的针对性只读 `badblocks` 复查,全盘只读 `badblocks`,以及修复后的接口读取压力检查.
- 支持交互式选择,批处理执行,持久化结果,复用及历史报告;可选通过临时 systemd 单元移交长时间运行的任务.
- 不涵盖数据恢复,写入模式 `badblocks`,安全擦除或文件系统修改.Bash 检查器仍是单次运行工具;可选的本地 Web 配套服务负责常驻控制与定时快速巡检.可选择纳入 SSD/NVMe,但 HDD 评分并非为全面诊断这些设备而设计.JSON 快照供 Web UI 使用;更深入的 SAS 评分和 NVMe 专用评分并非已实现目标.

## 架构

`src/checker/hdd-health-check.sh` 中的检查器实现通过仓库根目录的兼容入口调用.它以 `lsblk` 枚举磁盘,通过菜单或 CLI 选择目标,用 `smartctl` 探测 SMART 访问,执行指定模块并生成综合报告.ATA SMART 属性与 SAS/SCSI 缺陷/错误计数器使用不同的评分路径.快速检查包含挂载和内核日志证据;速度,盘面和接口检查使用原始设备读取.结果和每个设备的标识持久保存,供后续检查复用.交互式决定可通过受约束的计划传递给批处理进程;私有锁防止共用状态目录的实例并发运行.可用时由临时 `systemd-run` 单元处理后台任务;`--status` 和 `--stop` 查询已记录的实例.

完整批次以同一批次标记记录快速,短程,长程 SMART 检查及已完成的只读盘面扫描;网页批量选项展示所选磁盘支持的项目并集,仅适用于 HDD 的模块会跳过不适用的 SSD;HDD 还要求速度采样.SSD 慢读只记为性能变化,不扣健康分,但实际读取错误仍会扣分.批次末尾复查快速 SMART/ATA/CRC,记录扫描后的变化.只有同批次完整且有效的结果才有数字综合分数.复用,中断,过期,无批次标记的旧状态及之后的接口验证会让旧记录保持历史/待复查状态,总体等级为部分/未知.仅生成报告不会更新快检比较基线.接口验证另行记录已解决或未解决,不重新归因旧错误,也不让旧批次变成当前批次.没有先前快检计数的 ATA 总数仍属未解决风险(扣 5 分);后续检查和完整评估继续保留,即使旧记录缺少风险字段.总数增加扣 20 分;计数稳定既不证明问题解决,也不构成新错误.接口验证不能单独把 ATA 错误归因于接口维修.零星慢读提示复测性能,并非坏扇区诊断;反复发生的盘面读取错误仍扣 40 分.这些是启发式权重,不是故障概率.

快检通电时长作为使用信息显示,本身不扣健康分.ATA Pre-fail 属性的近阈值警告需要非零原始错误计数作佐证;没有保存原始证据的历史阈值警告改为待复查,不扣分.新警告记录包含 SMART 属性及实测值.关注卡片直接显示保存的检查原因.网页检查和停止确认采用可通过键盘操作的站内对话框,详情抽屉以型号为标题,设备路径列于其下.

固态盘的速度采样波动和与上次测试的平均速度变化只作为性能信息,不扣健康分;实际读取错误仍会扣分.已有速度结果也按相同规则显示,不修改磁盘状态文件.Web 磁盘列表按浏览器可用宽度自动安排卡片,宽屏最多六列;浏览器缩放改变可用宽度时卡片会重新排列.仪表盘的磁盘统计块可跳转到列表.前端源码位于 `src/web/`,构建到 `dist/web/`;`src/web/src/theme.css` 为浅色和深色模式的八套主题色定义语义变量.设置页将主题色和明暗模式分别保存在浏览器存储中,并在 Vue 挂载前恢复.Vite 嵌入构建版本并生成供 `/api/build` 使用的 `version.json`;更新记录从打包的源码中渲染对应的 `doc/<lang>/LOG.md`.磁盘序列号在外层列表和 SMART 详情中保持遮蔽,直到用户点击带标签的显示按钮;关闭详情后再次遮蔽.

## 设计约束

- 有效诊断需要 root 权限和物理 SMART 透传.USB/RAID 桥接检测基于启发式规则;透传失败会报告出来,而不会被推断为健康.SAS 评分独立于 ATA,验证也比 ATA 少.温度和阈值取决于厂商数据.
- 所有设备盘面和接口读取均输出到 `/dev/null`;调用 `badblocks` 时不使用破坏性的 `-w`.**启用 SMART 和运行自检可能修改磁盘固件状态**;主机路径也可写入.不可将此描述为零副作用执行.
- 显式选择及 `--include-ssd` 不意味着设备可安全承受负载.全盘盘面扫描可能耗时数小时;其他进程的操作系统写入仍会继续.`--stop` 不会终止磁盘内部运行的自检.
- 状态及计划数据仅按允许的字段解析,不作为 shell 代码执行.已有但不符合格式的状态可能被拒绝.主机状态目录不得为符号链接;脚本会检查目录和输出日志的符号链接,但调用者仍须保护自行选择的路径.

## 数据设计

`HDD_STATE_DIR` 默认位于 `/var/lib/hdd-health`(创建权限模式为 700).目录内有 `settings.conf`(结果有效天数,复用策略,并行度,扫描分块大小,采样参数,是否纳入 SSD 及自动复查策略),每盘 `.env` 结果文件,SMART 计数器 `history.csv`,修复日志,盘面扫描图/检查点,报告历史及可选的坏块列表.`.lock`,运行中实例数据和临时后台计划用于协调执行.默认设置包括结果有效期七天,64 MiB 盘面扫描分块和 24 × 128 MiB 速度采样.菜单可保存设置;`--rescan` 会覆盖复用策略.清除结果时可保留计数器/修复历史或一并删除;用户也可另行选择删除旧日志.

`HDD_LOG_DIR` 默认位于 `/var/log/disk-health`;`-l/--log` 选择单个日志的路径.日志为纯文本,可能包含设备标识,主机/内核信息和健康数据,应妥善保护.临时工作目录创建在 `/run` 下,或者回退到临时目录.不要假定日志是唯一的持久化输出,也不要假定新版状态目录在没有匹配备份时可回滚.

## 外部接口

| 接口 | 职责及影响 |
| --- | --- |
| `lsblk`,`blockdev`,`/proc/mounts`,内核日志 | 枚举设备,获取几何参数与挂载状态及 I/O 错误;可见信息受主机权限限制. |
| `smartctl` | 读取 SMART 诊断信息;可能启用 SMART 或启动内部自检.透传选项的自动检测基于启发式规则. |
| `dd`,`badblocks` | 对原始设备进行采样,接口负载,延迟扫描或只读坏块测试.读取可能加重受损硬件的负担. |
| `apt-get` | 提示安装缺少的软件包;`-y` 可自动同意.这会更改主机软件包,并可能需要网络访问. |
| `systemd-run` | 用于分离式任务的可选临时单元;`--stop` 请求停止脚本记录的进程,而非硬件自检. |

健康检查本身不使用网络 API.可选的本地 Web 服务在手动模式下使用回环 API;安装器启用带认证的局域网访问.`--json` 使用与终端报告相同的综合评分函数提供结构化只读快照.Web 登录发放短时效,仅供 HTTP 使用的会话 Cookie.安全验证会轮换该 Cookie,然后授予五分钟权限;改变状态的请求包含同源请求头作为 CSRF 防护.私有地址白名单启用后可在普通操作中跳过密码登录.Security Settings 将白名单,启用开关及密码修改置于服务端强制的五分钟权限之后,该权限通过管理员密码验证授予.仅通过 IP 进入的会话不能读取或修改这些设置.在权限有效期内,修改密码只需输入并确认新密码,无需再次输入当前密码;修改后所有会话失效.默认快照和 SMART 响应会遮蔽序列号;只有用户明确操作后,独立的认证显示接口才返回完整序列号.服务只在打开磁盘时按需读取 SMART 详情;其原始 SMART 结论不替代检查器的综合评分.`--no-install` 阻止无人值守调用时安装软件包.Web 架构,时间表及安全边界见 [WEB](WEB.md).Web 源码位于 `src/web/`,生成的构建产物位于 `dist/web/`;安装器将其复制进现有主机布局.脚本可使用退出码 `0` 健康,`1` 需关注,`2` 危险,`3` 运行失败;参见[指南](README.md#指南).

`lsblk` 提供磁盘快照中的已挂载文件系统信息.主页的一键评估可分别选择磁盘范围和检测项目.范围包括 SATA,机械盘,固态盘,NVMe 或全部磁盘;项目包括快速,SMART 短/长自检,速度,盘面,badblocks,接口复查和完整评估.服务端按当前枚举结果选盘,运行 `<module> --rescan` 后台批次.只有完整评估可能生成当前综合分数;SSD/NVMe 评分仍沿用机械盘规则,未单独校准.列表按传输协议和介质类型显示 SATA SSD,NVMe SSD 等,并在后台读取可用温度,避免唤醒休眠机械盘.详情页仅在设备明确报告时显示外形规格;不能仅凭 NVMe 或 SATA 判断是否为 M.2.SATA 版本和速率来自 smartctl 或 Linux sysfs;NVMe 的 PCIe 代际,通道数和链路速率来自 sysfs.点击通电时长可切换小时与年/天/小时.

需要关注卡片现在会筛出有警告或异常记录的磁盘.检测详情列出原因和扣分;旧记录扣分但未保存原因时会明确提示重新检查.后台任务从已提交,运行中到完成,停止或失败都会留下状态记录及最近日志.任务提交后 15 秒仍没有运行或结束记录时显示状态未确认.检测返回码 `1` 或 `2` 表示检查完成但发现问题,并非启动失败.

## 当前固态盘评估与操作

固态盘和 NVMe 的完整评估包括 SMART 快检,短测,长测及全盘只读扫描,不采样速度.单纯慢读不扣健康分;干净完成的批次得 100 分,SMART 异常或实际读取错误可能降低启发式评分.使用 `--include-ssd` 纳入 SSD 时,Web UI 只提供快检,短测,长测,全盘只读扫描及完整评估.点击容量和主机写入量可切换十进制与二进制单位.休眠 HDD 可在 SMART 详情页单独唤醒.
